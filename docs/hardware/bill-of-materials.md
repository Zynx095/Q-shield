# Bill of Materials (BOM)

This document lists the hardware components required to build the physical IoT endpoint for Q-SHIELD.

**Note:** The laptop acts as the primary compute hub and is not listed as an IoT component. We intentionally avoid using a Raspberry Pi for this design.

## Already Owned
- ESP32 Microcontroller
- Camera Module (Compatible with ESP32)

## Planned / To Acquire
- **BME280** - Temperature, Humidity, and Pressure Sensor
- **MPU6050** - Accelerometer and Gyroscope
- **Reed Switch** - Magnetic contact sensor for physical tamper detection
- **OLED Display (SSD1306)** - For visual status output
- **Buzzer** - For audio alerts during quarantine/recovery
- **RGB LED** - Visual trust status indicator
- **Push Buttons** - For manual interactions / resets
- **Breadboard** - Prototyping base
- **Jumper Wires** - Wiring
- **Resistor Kit** - Assorted values
- *(Optional)* **SG90 Servo** - To demonstrate a physical response mechanism
- *(Optional)* **Enclosure** - To house the prototype securely
