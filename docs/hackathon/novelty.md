# Project Novelty

The primary novelty of Q-SHIELD lies in the **integrated, closed-loop architecture**. We are not simply claiming that individual technologies (like AI or PQC) are new on their own, but rather that their unified application to autonomous IoT defense is novel.

## Key Novelty Themes

1. **Continuous Dynamic Device Trust**
   - Moving away from one-time static authentication (e.g., initial password/token exchange) to continuous evaluation of device behavior and physical state.

2. **Cross-Modal Signal Correlation**
   - Fusing cyber, physical, visual, and network signals to detect anomalies. A compromised network packet might be caught by an inconsistent physical sensor reading.

3. **PQC-Backed Device Identity & Secure Communication**
   - Securing the telemetry and command pathways using Post-Quantum Cryptography (ML-KEM/ML-DSA), ensuring long-term resilience against "harvest now, decrypt later" strategies.

4. **AI-Assisted Sensor/Behaviour Consistency Checking**
   - Leveraging machine learning to build an understanding of normal operations and rapidly identify deviations.

5. **Digital Twin Integration**
   - Maintaining an expected state of the device and continuously comparing it against the observed state to determine trust degradation.

6. **Tamper-Evident Incident Evidence Chain**
   - Cryptographically logging security events to create a verifiable timeline of compromise.

7. **Autonomous Quarantine and Recovery**
   - Reacting in real-time to isolate a threat, deploy recovery configurations, and carefully rebuild trust rather than relying purely on human intervention.

> **Note:** The novelty is the integration and closed-loop architecture.
